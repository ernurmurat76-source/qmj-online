# QMJ Online

Қазақстан мұғалімдеріне арналған ҚМЖ және оқу материалдарын құрастыру платформасы.

## Мүмкіндіктер

- міндетті тіркелу және аккаунтқа кіру;
- ҚМЖ, БЖБ/ТЖБ, тапсырма, презентация, тест, ойын, көрнекілік және мақала конструкторлары;
- OpenRouter Free арқылы ЖИ генерациясы;
- API кілті жоқ кезде жұмыс істейтін жергілікті демо үлгі;
- әр мұғалімнің жеке мұрағаты;
- материалды көшіру және Word форматында жүктеу;
- телефон мен компьютерге бейімделген дизайн.

## Компьютерде іске қосу

Node.js 18 немесе жаңа нұсқасы қажет.

```bash
npm start
```

Сайт: `http://localhost:3000`

OpenRouter қолдану үшін PowerShell-де:

```powershell
$env:OPENROUTER_API_KEY="сіздің_кілтіңіз"
npm start
```

## Render-ге орналастыру

- Language: `Node`
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `OPENROUTER_API_KEY`
- Health Check Path: `/api/health`

`package.json` және `server.js` GitHub репозиторийінің түбірінде тұруы керек.

## Маңызды ескерту

Бұл MVP деректерді сервердегі `data/store.json` файлына сақтайды. Render Free сервері қайта құрылғанда файл жоғалуы мүмкін. Тұрақты қоғамдық іске қосу алдында PostgreSQL немесе Supabase дерекқорын жалғау керек.
