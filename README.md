# QMJ Online

Қазақстан мұғалімдеріне арналған онлайн ҚМЖ құрастыру сервисінің алғашқы интерфейс қаңқасы.

## Іске қосу

`index.html` файлын браузерде ашыңыз немесе осы бумада жергілікті сервер іске қосыңыз:

```bash
python3 -m http.server 8080
```

Содан кейін `http://localhost:8080` адресіне кіріңіз.

## Қазір жұмыс істейтін мүмкіндіктер

- телефон және компьютерге бейімделген басты бет;
- ҚМЖ құрастыру формасы;
- толтырылған мәліметтен демо жоспар көрсету;
- жоспарды браузерде сақтау;
- қарапайым `.doc` файлын жүктеу;
- тіркелу және кіру терезесінің интерфейсі.
- мұғалімнің толық кабинеті (`dashboard.html`);
- ҚМЖ, БЖБ/ТЖБ, тапсырма, презентация, тест, ойын, көрнекілік және мақала құралдары;
- материалды жергілікті мұрағатқа сақтау, іздеу және өшіру;
- қолдану статистикасы мен тегін лимит индикаторы.

## Келесі кезең

Нақты пайдаланушы аккаунты, дерекқор, ЖИ арқылы толық ҚМЖ генерациясы, шынайы DOCX/PDF экспорты, төлем және әкімші панелі сервер қосылғанда іске асырылады.
